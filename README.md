PRACTICA DE CONECTIVIDAD

Lenguaje utilizado:
- Python 3
- Framework Flask

Base de datos:
- MySQL
- Nombre de la base de datos: bd1inf132

Dependencias:
- Flask
- Flask-MySQLdb
- mysqlclient

Pasos para ejecutar:

1. Importar el archivo ScriptBD.sql en MySQL.
2. Verificar que el servidor MySQL esté iniciado.
3. Instalar las dependencias:

   pip install Flask Flask-MySQLdb mysqlclient

4. Ejecutar la aplicación:

   python app.py

5. Abrir el navegador y acceder a:

   http://127.0.0.1:5000

La aplicación permite ejecutar consultas SQL (SELECT, INSERT, UPDATE y DELETE) sobre la base de datos y mostrar los resultados en una página web.
